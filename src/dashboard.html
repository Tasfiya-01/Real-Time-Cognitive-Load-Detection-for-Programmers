How the brain state is made

No headset is connected. The monitor plays back recorded EEG of participant P05 from the Peitek et al. program-comprehension study, one 5-second window every 5 seconds. The XGBoost model was trained on nine other programmers to tell code reading from rest, so P05 is new to it. With a live headset only the data source changes.

Replay mode shows the snippet P05 was reading in each window. Snippets: Peitek et al., NoviceVsExpert replication package (CC BY-SA 4.0); complexity measured with lizard. Live mode analyses your own Python code with radon.
